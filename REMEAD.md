# Automação com Selenium

Este script usa Python e Selenium para acessar a página de um produto na FastShop e clicar automaticamente no botão "Comprar".

## Instalação

Primeiramente instale o Selenium no seu computador.

```bash
pip install selenium
```

## Como usar
Execute o script com o nome "automacao"

```python
automacao.py
```
O navegador abrirá automaticamente, acessará o produto e clicará no botão de compra.
